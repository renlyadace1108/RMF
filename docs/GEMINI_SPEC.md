# RMF Gemini AI 监管与智能化中枢设计规范

RMF 将 Google Gemini API 作为整个系统的“智能大脑与全能管家”。
Gemini 赋能三大核心功能：**AI 执行监管与日常复盘**、**智能自然语言收支记账**、**日程智能排布与冲突拆解**。

---

## 1. AI 监管中枢 (AI Supervisor)

### 1.1 工作原理
1. **数据输入**：
   * **计划侧**：当天所有计划日程块（如：09:00-11:30 编写代码；14:00-15:30 撰写技术文档）。
   * **实际执行侧**：
     * Windows 采集到的真实活跃窗口日志（聚合为每个应用占用的分钟数与分类，如 VSCode 120min，Bilibili 45min）。
     * 移动端/平板端打卡的番茄钟与专注时段。
2. **监管机制**：
   * **即时预警（软提醒）**：如果在“深度专注”时段内检测到连续 15 分钟以上的非相关应用或闲置，发出轻度托盘/状态栏提示。
   * **晚间全量复盘报告**：每日晚间（如 22:30）自动汇总生成客观、毒舌或温和（可配置）的复盘报告，打出计划契合度评分 (0-100)。

### 1.2 Gemini Prompt 设计示例（每日复盘）

```text
System: 你是 RMF (Renly Manage Platform) 的核心 AI 监管管家。你的职责是严格而建设性地评估用户今日的执行力，发现拖延模式与时间黑洞，并给出针对明日的可执行优化建议。

User Prompt:
【今日计划日程】
1. 09:30 - 11:30 编写 RMF 同步模块代码 (标签: 工作/核心)
2. 14:00 - 15:30 整理团队周报与架构设计 (标签: 工作)
3. 20:00 - 21:00 健身与力量训练 (标签: 健康)

【实际执行与设备采集数据】
- 09:40 - 11:45 活跃窗口: devenv.exe (VS Code/Visual Studio) -> 125分钟
- 14:00 - 14:20 活跃窗口: msedge.exe (访问知乎/微博) -> 20分钟
- 14:20 - 15:30 活跃窗口: WINWORD.EXE (文档整理) -> 70分钟
- 20:00 - 20:45 移动端番茄钟记录: 健身房打卡 -> 45分钟

请输出 JSON 格式的复盘分析：
{
  "adherence_score": 88,
  "summary": "简短总结今日执行情况",
  "distraction_analysis": "分析下午启动任务时的拖延情况",
  "tomorrow_suggestions": ["具体建议1", "具体建议2"]
}
```

## 2. 智能自然语言收支记账 (Smart Bookkeeping)

无需手动在一个个下拉框中点选“分类”、“账户”、“金额”。支持用户直接在输入框打字或语音输入一句话，由 Gemini 结构化抽取。

### 示例交互：
* **用户输入**：“中午在楼下吃了32块牛肉面，微信钱包付的”
* **Gemini 结构化抽取为**：
  ```json
  {
    "type": "EXPENSE",
    "amount": 32.00,
    "currency": "CNY",
    "category": "餐饮美食",
    "sub_category": "午餐",
    "account": "微信钱包",
    "note": "牛肉面",
    "transaction_time": "2026-10-03T12:30:00Z"
  }
  ```

## 3. 智能排程与任务拆解 (Smart Planner)

* **用户输入**：“我需要在周四下午下班前完成一份 15 页的汇报 PPT，预计耗时大约 4 个小时，请帮我排入日程表。”
* **Gemini 计算逻辑**：
  * 读取周一到周四现有的空白时间块；
  * 自动将 4 小时大任务拆分为两个 2 小时的专注时间块；
  * 避开既有会议与作息时间，自动向日程表插入待办项并附带前置提醒。
